Configuración

Precio por hora

Este importe se propondrá automáticamente al crear cada riego. Podrás modificarlo en un riego concreto si hace falta.

Cómo se calcula

Total = horas trabajadas × precio por hora. El importe se actualiza automáticamente al cambiar cualquiera de los dos valores.

Copias de seguridad

Guardar mis datos

Descarga una copia con campos, riegos, importes, precios por hora y pagos. En iPhone podrás guardarla en Archivos o iCloud Drive.

Recuperar mis datos

Selecciona un archivo JSON anterior. Se sustituirán los datos actuales.

Consejo: guarda una copia cada semana y después de cambios importantes. Si borras los datos del navegador o cambias de móvil, podrías perder la información local.

Los datos se guardan en este dispositivo. No hay cuenta ni sincronización automática.
